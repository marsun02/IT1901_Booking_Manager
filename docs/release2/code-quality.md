## Code-quality

To ensure high code quality we follow several practices throughout our development. Firstly, we try to cover as much of our codebase with Junit tests as possible, as that helps us verify the code behaves as expected. It also assures us that new changes don’t unintentionally break existing functionality. As the project evolves, we regularly update our test coverage to include the new features. In addition to this, we also use both Checkstyle and Spotbugs to automatically detect potential issues. Checkstyle ensures consistent coding conventions, while we use Spotbugs to identify possible bugs in the compiled code. Furthermore, we also use peer reviews to ensure high quality. Whenever a pull request is made, another team member will review the changed files to ensure the code is efficient and serves its purpose.
