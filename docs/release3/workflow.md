## Workflow for release 3

Throughout the period of the project we have had weekly meetings where we update each other on what we have been working on. The meetings are usually more productive for us, as we are contributing a lot more and can help each other with the code. For the 3rd release, we've had more frequently meetings, and worked a lot more intense on the project. We've been setting up a lot of issues on our project board, and assigning them consistently. The issue board helps us know exactly what everyone is working on and that prevents us from getting any unnecessary conflicts that would steal time from us. One thing that came up close to the submission deadline, was that we noticed one of our group members had used their own github account when trying to push to the NTNU one. He was able to fix this and update to his NTNU user, but this created a lot of issues for other team members, as they were getting troubles creating pull requests.
