## Use of AI tools
   We do not use AI tools to generate the code, because it makes it harder to guarantee a certain quality. We do however use AI tools to generate files that are less critical to the project, for example the .gitignore file is generated by ChatGPT. A comment is also left in the file. We then double checked that the file looked good and made ajustments to make sure everything worked as expected. We have also used AI to get an understand of what causes certaint issues relating to git. In addition, we created two md files and a section of the main README file using google gemini. The files we generated was "commit-messages.md" and "pr-checklist.md", both located in the "work-practices" folder. The section of the Main README that is generated by gemini is the part refering to the "work-practices" files. Comments have been left in all of the files created using AI.
