## Use of AI tools
   We do not use AI tools to generate the code, because it makes it harder to guarantee a certain quality. We do however use AI tools to generate files that are less critical to the project, for example the .gitignore file is generated by ChatGPT. A comment is also left in the file. We then double checked that the file looked good and made ajustments to make sure everything worked as expected.
