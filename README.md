# Project

## Quick description
This is a project that allows users to book tables at restaurants.

## Features
- Shows a list of available tables in the selected restaurant
- Allows the user to book the desired table
- Prevents double booking by checking availability before completing the booking process
- Supports multiple users on the same booking management system

## How to run
1. Clone the repository:
   ```bash
   git clone git@git.ntnu.no:IT1901-2025-groups/gr2515.git
   ```

2. Navigate to correct directory:
   ```bash
   cd javafx-app/
   ```

3. Compile code:
   ```bash
   mvn clean compile
   ```

4. Start app:
   ```bash
   mvn javafx:run
   ```

## Run tests

Run tests with this command:
   ```bash
   mvn test
   ```

## Versions and dependencies
   Java/javafx 23.0.1
   Maven: 17

## Use of AI tools
   We do not use AI tools to generate the code, because it makes it harder to guarantee a certain quality. We do however use AI tools to generate files that are less critical to the project, for example the .gitignore file is generated by ChatGPT. A comment is also left in the file. We then double checked that the file looked good and made ajustments to make sure everything worked as expected.
